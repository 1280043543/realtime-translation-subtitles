# 实时翻译字幕

**Windows 桌面软件，当前为预览版。** 读取电脑正在播放的声音，在本机完成语音识别和翻译，将原文、译文显示在主界面及可拖动的悬浮字幕窗口中。

## 1. 项目解决什么问题

观看没有合适字幕的外语视频、直播或课程时，通常需要一边听一边查词，难以连续理解内容。本项目通过“播放声音 → 识别原文 → 本地翻译 → 悬浮字幕”，辅助理解正在播放的内容。

它读取的是所选播放设备的**系统回环音频**，不使用麦克风，也不是浏览器插件。模型准备完成后，无需调用付费云端识别或翻译 API；音频与文本在本机处理。

## 2. 主要功能

| 功能 | 当前实现 |
| --- | --- |
| 系统播放声音采集 | 采集所选扬声器或耳机的播放声音；选择“跟随系统默认播放设备”时，可跟随默认设备变化重新采集 |
| 本地识别与翻译 | 使用 Qwen3-ASR-0.6B 识别原文，使用本机 Ollama 中的 Qwen3 模型翻译 |
| 目标语言 | 简体中文、英语、日语、韩语、法语、德语、西班牙语 |
| 两种字幕模式 | “语义优先”采用约 4 秒的分段目标，“速度优先”约 2 秒；遇到停顿会提前提交，已开始的停顿也可能略延后提交 |
| 后文修正 | 连续讲话被强制分段后，下一次识别会结合上一段音频更新字幕；显示措辞可能随之变化 |
| 悬浮字幕 | 置顶、拖动、适配屏幕；6 秒没有新字幕后淡出，开启状态下有新字幕时重新出现 |
| 外观与偏好记忆 | 字号 16～48 px，白色／暖黄色／浅青色，背景不透明度 20%～95%；记住字幕位置、外观、目标语言、模式和主窗口位置与大小 |
| 暂停与继续 | 暂停后保留已加载的识别模型，继续时复用；空闲时可单独释放识别模型 |
| 故障与积压处理 | 单次翻译失败时保留原文并继续监听；音频积压时跳过旧音频并重置上下文 |

**分段目标不等于端到端延迟保证。** 实际出字幕时间还包括识别、翻译和等待队列，受电脑性能、音频内容及负载影响。

## 3. 安装方法

### 环境准备

- Windows 64 位环境。
- 在线安装程序会自动下载 64 位 Python 3.11、Ollama 和项目依赖，不需要手动安装。
- 首次安装需要联网下载依赖和模型，并预留数 GB 下载及磁盘空间。推荐 NVIDIA 显卡；CPU 也可运行，但较慢。

### 安装步骤

1. 从 [Releases](https://github.com/1280043543/realtime-translation-subtitles/releases) 下载 `RealtimeTranslationSubtitles-1.0.0-Online-Setup.exe` 并运行。
2. 安装程序会自动下载 Python、Ollama 和项目依赖；随后首次启动会从 Qwen 官方 ModelScope 模型库下载 ASR 模型，并通过本机 Ollama 下载翻译模型。整个过程需要联网和数 GB 磁盘空间。
3. 安装完成后，从桌面或开始菜单的“实时翻译字幕”快捷方式启动。

安装脚本检测到可用的 `nvidia-smi` 时安装 CUDA 12.6 版 PyTorch，否则安装 CPU 版；使用 NVIDIA 加速需要兼容的驱动。若找不到 Python、需要指定 Python 路径或强制 CPU 安装，请查看 [手动安装说明](DEVELOPMENT.md)。

> 在线安装包只包含安装程序和客户端源码，Python、Ollama、第三方运行库及模型会在安装过程中从各自官方来源下载。没有网络时可按 [开发说明](DEVELOPMENT.md) 使用源码安装流程。

项目同时提供完整离线安装包的构建配置；由于体积约数 GB，默认 Release 使用在线安装包。离线包生成流程见 [开发说明](DEVELOPMENT.md)。

## 4. 使用方法

1. 双击桌面的 **“实时翻译字幕”**，或项目根目录的 **`启动.cmd`**。
2. 在“系统播放设备”中保留 **“跟随系统默认播放设备（推荐）”**；如果手动选择设备，应与视频实际输出声音的设备一致。需要重新手动选择时，先暂停，再刷新设备列表。
3. 在“翻译成”中选择目标语言，并选择字幕模式：理解完整表达优先选“语义优先”，更在意等待时间可选“速度优先”。
4. 点击 **“开始监听”**，等待模型加载并显示正在监听的状态，再播放未静音的视频。可先在主界面查看“识别原文”和“翻译字幕”。
5. 点击 **“开启悬浮字幕”**，按住字幕区域拖到合适位置。展开 **“字幕外观”**，调整字号、颜色与背景不透明度。
6. 暂时不用时点击 **“暂停”**，之后点击 **“继续监听”**；想释放识别模型占用的内存／显存时，先暂停，再点击 **“释放识别模型”**。

“释放识别模型”不等于卸载 Ollama 中的翻译模型，翻译模型由 Ollama 单独管理。模型已下载后，日常识别与翻译在本机进行。

### 没有字幕时先检查

- 视频是否正在播放且没有静音，输出设备是否选对；主界面“声音输入”是否显示有声音。
- 是否已等待模型加载完成；Ollama 是否可连接、所需翻译模型是否已下载。
- 主界面有译文但看不到悬浮窗口时，检查是否开启了悬浮字幕；超过 6 秒没有新译文时，窗口淡出属于当前设计。

启动报错可查看项目内的 `.local/logs/client.log` 和 `.local/logs/output.log`。

## 5. 输入输出实例

输入是**视频、直播或其他软件正在播放的音频**，不是文本输入框，也不是上传的视频文件。输出是主界面及悬浮窗口中的识别原文与翻译字幕。

| 播放的音频内容 | 目标语言 | 识别原文示例 | 翻译字幕参考 |
| --- | --- | --- | --- |
| 英语视频说：“We should discuss this face to face.” | 简体中文 | We should discuss this face to face. | 我们应该面对面讨论这件事。 |
| 中文视频说：“我们明天见。” | 英语 | 我们明天见。 | See you tomorrow. |

以上用于说明输入输出形式，不保证每次逐字一致。发音、背景音乐、多人讲话、断句和上下文都可能影响识别及译文。

## 当前限制

- 需要实际可采集的播放声音；**尚未实现静音视频识别或读取视频缓存提前翻译**。
- 采集所选设备的混合播放声音，不能只锁定某一个视频软件；其他应用的声音可能混入。
- 使用分段识别与翻译，存在延迟和误译；“语义优先”与后文修正不能保证完整断句或准确翻译所有短语。
- 普通窗口下使用置顶悬浮窗口，**不保证覆盖所有独占全屏或受保护的视频窗口**。
- 当前没有视频文件导入、手动文本翻译输入、字幕文件导出或屏幕文字识别功能。
